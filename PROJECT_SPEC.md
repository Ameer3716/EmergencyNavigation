# Project specification

The authoritative requirements are the user's project brief in this conversation. The implementation will compare four configurations: Fog + Cloud + A*, Mist + A*, Mist + Dynamic A*, and Mist + Dynamic A* + Fog fallback. The base scenario uses a shared SUMO network, demand, accident event, RSU placement, traffic-light programs, radio settings, and matched random seeds. Verification status is tracked in `docs/PROGRESS.md`; no results are reported until genuine simulator runs complete.
