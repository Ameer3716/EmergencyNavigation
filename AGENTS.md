# Project rules

- Preserve the requested target versions: OMNeT++ 6.3.0, Veins 5.3.1, SUMO 1.18.0, INET 4.6.0 if required. Explain any version change before making it.
- Use native Veins IEEE 802.11p unless direct INET integration is necessary. Never combine radio models in one vehicle.
- Never label a feature validated without an executable test and saved evidence.
- Keep the four experimental configurations on one codebase with identical scenario inputs and seeds.
- Record raw results without manual modification. Derive processed tables and graphs from the raw files.
- Complete and commit each validated stage before advancing.
