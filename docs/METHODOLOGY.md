# Methodology

The SUMO scenario uses a 4 × 4 grid with 300 m spacing and signalized intersections. Low, medium, and high traffic use normal-vehicle departure headways of 5.0, 2.5, and 1.8 seconds respectively during 0–360 s, generated by SUMO `randomTrips.py` with a fixed seed. The four OMNeT++ configurations must reference the same route file for each density/seed pair. The accident occurs at 60 s; the stopped accident vehicle is near D3 and SUMO parking keeps the road traversable. The ambulance departs at time 0 and waits near its fixed start until it receives a route decision; the SUMO-only validation uses a fixed stop until 65 s.

Communication, routing, latency, fallback, preemption, and metric implementation are pending. Their formulas and validation will be documented as each stage passes.
